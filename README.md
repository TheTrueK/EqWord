# EqWord

AI输出文本意转 Word 格式，支持 LaTeX 公式转换、表格整理和快捷键直接粘贴。**免费使用，不限次数。**

## 主要功能

- **公式自动编号**：可自行开启编号、选择编号样式，转换后可在 Word 中编辑、更新。
- **快捷键粘贴**：复制内容后，按 `Ctrl+Shift+V` 转换并直接插入。
- **表格整理**：支持将表格整理后写入 Word/WPS 或 Excel。
- **历史记录**：之前转换的结果可再次复制、另存。

## 使用方法

1. 复制需要处理的正文、公式或表格。
2. 在 Word/WPS 文档或 Excel 单元格中放好光标。
3. 按 `Ctrl+Shift+V`，结果会直接插入。

启动后在 Windows 右下角系统托盘找到 EqWord，右键可打开设置和历史记录。**公式编号需在自定义设置中开启。**

使用时需已安装相应的 Word/WPS 或 Excel 软件，Excel 主要用于接收表格。

## 提示

极少数公式可能出现乱码，可能与 AI 输出格式或复制时格式丢失有关，可换一种复制方式重试。
